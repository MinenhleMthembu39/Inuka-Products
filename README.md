# Inuka Products Website

## 1. Project Overview

Inuka Products is a business website designed to provide visitors with information about the company, its products, business opportunities and success stories.

The website aims to create an accessible and user-friendly online platform where customers can explore products, learn about the business and contact the company.

## 2. Website Pages

The website consists of the following pages:

- **Homepage:** Introduces Inuka Products and provides website navigation.
- **About Us:** Provides information about the company, its background and values.
- **Products:** Displays available products and provides product search and category filtering.
- **Contact Us:** Allows visitors to find contact information and communicate with the business.
- **FAQ:** Provides answers to frequently asked questions.
- **How to Start Your Business:** Explains how visitors can get started with their own business.
- **Grow Your Business:** Provides information and guidance on business development.
- **Success Stories:** Shares business success stories and inspiration.

## 3. Technologies Used

The website was developed using:

- **HTML5:** Used to structure the website pages.
- **CSS3:** Used for website styling, colours, layouts and responsive design.
- **JavaScript:** Used to create interactive website features.
- **Git and GitHub:** Used for version control and project hosting.
- **GitHub Pages:** Used for website deployment.

## 4. Website Features

The Inuka Products website includes:

- Navigation menu for moving between website pages.
- Product search functionality.
- Product category filtering.
- Product image enlargement functionality.
- Responsive website layout.
- Consistent styling across website pages.
- Contact and information pages.
- Search engine optimisation files, including robots.txt and sitemap.xml.

## 6. How to Run the Website

To view the website locally:

1. Download or clone the Inuka Products repository.
2. Open the project folder in Visual Studio Code.
3. Make sure all HTML, CSS, JavaScript and image files are in their correct locations.
4. Open the homepage HTML file in a browser or use the VS Code Live Server extension.
5. Navigate through the website to test its pages and features.

## 8. Website Deployment

The website is intended to be published using GitHub Pages.

To configure deployment:

1. Open the GitHub repository.
2. Select Settings.
3. Open Pages.
4. Select Deploy from a branch.
5. Select the main branch.
6. Select the root folder.
7. Save the settings.

Note: GitHub Pages normally uses index.html as its default homepage. Ensure that the main homepage is named index.html in the repository before publishing.

## 9. Project Maintenance

The website can be updated by modifying the HTML, CSS and JavaScript files in Visual Studio Code.

To upload changes to GitHub, use:

```bash
git add .
git commit -m "Update Inuka website"
git push origin main
```

The Inuka Products website provides an online platform for presenting the company's products, sharing business information and helping visitors learn more about starting and growing a business.
